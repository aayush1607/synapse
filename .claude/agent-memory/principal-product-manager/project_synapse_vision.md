Synapse is a habit tracking app with internal tagline "Hardwire the Habit."

Core design pillars:
1. Dopamine-driven gamification on check-off (animations, haptics)
2. Neuroplasticity metaphor — streaks as growing neural pathways (thicker = stronger)
3. Friction-free — under 5s check-in, max 3-5 habits, binary completion only
4. Loss aversion — missed days show "fraying" not instant reset, "Never Miss Twice" buffer
5. Variable notifications to prevent habituation

**Why:** The user is building this as a personal/fun project but wants implementation-ready specs.

**How to apply:** All product recommendations should reinforce these five pillars. Resist feature creep that adds friction or complexity beyond the core loop.
